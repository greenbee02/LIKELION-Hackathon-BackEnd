# MVP 범위

## 현재 상태

구매 경험을 QR로 인증하고 디지털 카드로 소장하는 핵심 흐름과 카드 커스터마이징 기반이 구현되어 있다.

## MVP 포함 기능

### 인증

- 회원가입·로그인
- JWT 인증
- 회원 탈퇴 및 소프트 삭제

### 상품·컬렉션 탐색

- 상품·경험 목록 및 상세 조회
- 상품 유형·카테고리·테마·시즌·지역·한정 여부 필터
- 공식 컬렉션 목록·상세·소속 상품 조회
- 카드 템플릿 조회

### 디지털 카드

- 구매 QR 기반 카드 등록
- QR 중복 사용 차단
- 카드 목록·상세 조회
- BASIC·COLLECTOR·CUSTOMIZE 카드 타입
- 카드 커스터마이징 Mock 생성
- 커스터마이징 선택 및 원본 복원

### AI 리소스 기반 카드 꾸미기

- 배경·테두리·패턴·상품 각도 등 리소스 생성 요청
- 비동기 생성 상태 관리
- AI 리소스 여러 개를 카드에 조합
- 조합 결과를 카드 커스터마이징으로 저장

실제 OpenAI 이미지 생성은 API 연동까지 구현되어 있으며, 이미지 API 크레딧·한도 설정 후 운영 검증한다.

## 후순위 기능

- 사용자 컬렉션 생성·수정·삭제
- 카드 추가·제거 및 달성률 계산
- 리워드 발급·수령·만료
- 이벤트 관리
- 실물 카드·리워드 패스
- 운영자·매장 직원 기능
- AI 생성 결과의 S3 등 영구 저장소 전환

## MVP 완료 기준

- 사용자가 회원가입·로그인할 수 있다.
- 유효한 구매 QR로 카드 1장을 발급할 수 있다.
- 같은 QR의 중복 발급이 차단된다.
- 사용자가 자신의 카드만 조회·수정할 수 있다.
- 상품·공식 컬렉션을 탐색할 수 있다.
- 카드 원본을 유지하면서 커스터마이징 이력을 저장할 수 있다.
- AI 리소스 생성 결과를 카드 조합에 사용할 수 있다.
- H2 통합 테스트가 통과한다.
